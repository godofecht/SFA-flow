# Slow Feature Analysis in Flow

Native Flow implementation of the adaptive Stone–Bray slow-feature learning experiments in [Slow-Feature-Analysis](https://github.com/godofecht/Slow-Feature-Analysis).

The port is being developed with separate numerical tests and documented deviations from the historical C++ code. The source of truth for the language is [Flow](https://github.com/flooooooooooow/flow).
