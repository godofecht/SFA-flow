01 — THE RESEARCH QUESTION

What changes least
when everything moves?

Ordinary signal representations emphasize the values we observe. Slow Feature Analysis (SFA) instead searches for projections whose temporal variation is small. The experiments here probe whether an adaptive network can recover slowly varying structure from phase-modulated one-hot signals.

The learner runs a burn-in period, then online adaptation using running statistics, weight updates and, in the two-output case, a decorrelation mechanism. This is a scientific implementation showcase—not a claim of independently established numerical equivalence with the C++ reference.

03 — INSIDE THE MODEL

From changing observations
to persistent structure.

The native Flow port preserves the learning sequence and key mathematical choices of the source implementation. It deliberately documents its differences rather than hiding them.

01 / ENCODE

One-hot input

A periodic 101-position signal, or paired 51 × 51 phase-modulated signal, supplies fast-changing observations.

101 → 1   |   2601 → 2
02 / ESTIMATE

Two time scales

Running long- and short-timescale means and variances reveal how rapidly a learned output changes.

γₗ = 0.5^(1 / 2ρ)
03 / LEARN

Online adaptation

Adaptive weight updates optimize the ratio of long- to short-timescale variation. The paired case adds anti-Hebbian suppression.

α = 0.001
04 / VERIFY

Reproducible runs

What this evidence does—and does not—establish

Passing CI demonstrates the tested Flow code executes and produces finite, correctly shaped experiment data. It does not establish scientific trajectory parity, matched random initialization or GPU performance relative to the original C++ implementation. The Flow port also uses deterministic Park–Miller initialization and safer handling of zero-variance startup conditions.
